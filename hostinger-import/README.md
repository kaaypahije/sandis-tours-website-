# Hostinger SQL Import

Use one of these options in Hostinger phpMyAdmin after selecting the database.

## Option A: Import Two Files

1. Import `01-schema.sql`
2. Import `02-default-data.sql`

## Option B: Import One File

Import `hostinger-full-import.sql`.
